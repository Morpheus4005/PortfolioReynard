Astro-ACE

Game Development • Unity • C#

Astro-ACE is a 2D bullet-hell arcade game inspired by the Touhou Project series and developed for an indie game competition.

I was responsible for implementing player movement, shooting mechanics, enemy spawning, bullet patterns, and debugging script interactions between game objects.

Through this project, I improved my understanding of Unity game development, object-oriented programming, and teamwork while working under competition deadlines.

My Contributions

  • Implemented player shooting mechanics.
  • Developed enemy spawning and attack patterns.
  • Fixed prefab and collision issues.
  • Assisted in balancing gameplay difficulty.
